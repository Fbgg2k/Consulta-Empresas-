# Frontend — Consulta de Empresas

Interface React criada com Vite para consultar empresas por CNPJ.

## Executar localmente

```bash
cd frontend
npm install
npm run dev
```

Acesse `http://localhost:5173` em outro terminal com o backend executando na porta `3001`.

Consulte o [README do projeto](../README.md) para a documentação completa.
